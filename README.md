# Reloj de Fibonacci

Reloj en una sola página (`index.html`, sin dependencias) que da la hora con cinco cuadrados de Fibonacci (5, 3, 2, 1, 1) o con una espiral áurea sobre una placa plateada, con el cielo real del momento.

Funciones: modo en vivo, modo práctica, control para mover la hora, números visibles/ocultos y vista de cuadrados o manecillas.
